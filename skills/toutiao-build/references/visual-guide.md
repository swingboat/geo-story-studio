# 今日头条图文视觉规范

## 已选定的制作方向

用户对流星篇 v005 的封面与连续场景插图给出正向反馈。本规范将其作为后续作品的视觉参考，反馈范围为设计效果。参考身份、出处与文件哈希保存在 [visual-baseline.json](visual-baseline.json)。

默认面向对地理和自然科学好奇的普通成年人，兼顾高中生；具体任务指定其他读者时按其需求调整。用生活现象提出问题，先给简短回应，再补概念、依据与过程。正文长度和图数服务解释任务。

## 封面与正文图的分工

- 封面突出一个问题或对照关系，用少量大字配清楚主体；品牌标识居次。将标题、画面含义与正文结论一同核对。
- 将关键文字和主体留在裁切安全区域，查看约320px缩略图及16:9、4:3、1:1居中裁切。比例用于本地审阅，实际规格以发布时的编辑器为准。
- 实景首图交代实际看到的对象，图注保留拍摄说明和出处。列表封面是否进入正文单独决定。
- 过程图在同一场景中安排位置、光线、路径和文字；比较任务可用并列图或表格。每张图先写一句解释用途，合并重复信息。

## 连续场景插图的制作要点

1. **先搭信息骨架。** 标记主要对象、过程节点、结果与条件，再布置场景；有条件的结果分出独立路径。图上的大小变化、箭头和颜色同样属于科学表述。
2. **画出可辨认的主体。** 根据题材增加轮廓、受光面、阴影、纹理和局部细节。粒子、星空、云层等辅助元素避开文字区域，保留阅读留白。
3. **用层次连接过程。** 流星图使用深蓝太空、渐变大气、暖色光迹和弧形地面。新题材选择相应环境，主要文字与背景保持清楚对比；颜色同时配标签，不能独立承担分类。
4. **按手机尺寸检查。** 以约1200px宽绘图时，主概念可用70—82px、主要说明44—50px，辅助说明按重要性缩减。导出后实际查看343—375px宽版本，再决定断行、字号和详略；这些数值是起点。
5. **核对示意边界。** 画面注明必要的不按比例、概念化和条件限制。原审校要求同步落实到图内文字、图注与alt；美化引入新机制或新结论时先补审校。

建议使用的色彩关系：深蓝 `#081426`／`#112b43`，中间层蓝 `#24526a`，暖金 `#efb34c`，主要文字 `#f8f4e9`，次要文字 `#d7e4eb`。浅底图沿用深色文字与暖色强调，保证系列识别。

## 成品检查与记录

查看导出的PNG原尺寸和手机宽度版本，核对文字截断、重叠、主体识别、分支去向及图文一致；摄影与示意组合应能区分。浏览器可用时再查看实际文章排版，受限时记录已完成的检查范围。

在 `editorial_review.notes` 写明视觉依据、实际查看的尺寸与仍需处理的问题。来源、许可、处理和文件哈希进入media记录；科学准确、读者理解与设计检查分别记录。真实读者试读和流量效果只有实际发生后才记录。
