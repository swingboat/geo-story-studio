# 抖音分镜视觉规范

## 系列风格

延续项目已选定的深蓝、暖金和有材质的连续场景。共享视觉依据为 `skills/toutiao-build/assets/scene-process-reference.svg`；制作前可查看同名PNG。新构建记录实际引用的基准路径与哈希。旁白和知识范围独立引用科学审校素材。

为竖屏镜头重新布局对象和留白。每个镜头集中说明一个问题，让标题、主体和字幕各有位置；按过程安排景别和运动。关键帧预演呈现构图与时间计划，后续动画版让对象和字幕随时间变化。

## 画面层级

- 开场：用真实问题配明显主体，简短文字迅速建立语境。
- 概念：突出一个主概念，旁边是岩石、光迹或地面等对应对象；可用次要说明解释关系。
- 过程：为进入大气、亮迹出现和物质变化预留独立动画对象。运动必须表达有依据的过程。
- 条件：耗尽与幸存分两条可辨路径；保留“若”“部分”等限制，不仅靠颜色区分。
- 回顾：用简短关键词回答开场问题，画面中的对象继续与概念对应。

在1080×1920稿中，关键文字与主体先留在左80—右190、上180—下330的内侧区域，字幕约置于下部但避开最底端。上述为本地构图预留，发布时按实际抖音界面检查。查看375px宽输出后调整字号、行长与信息量。

插图的暗部保留形状，光迹有亮度层次，星空和颗粒避开文字。图上注明科普示意和必要的不按比例。分镜先记录进入、停留、转场和结束的变化，动画阶段再落实为可独立运动的对象；不能只对整张图缩放就称为过程动画。

条件分支先后展开，标签出现时箭头绕开文字；耗尽路径不通向地面陨石。标题和字幕保持稳定可读，主体运动不进入字幕区。回顾镜头按讲解顺序显示概念。每镜检查动画早晚帧，保留暂停阅读的空间。

## 本地预演

预演默认暂停，提供播放、暂停、时间拖动与镜头按钮，使用键盘也能操作。显示“无声关键帧预演”和“字幕时间暂定”，避免将规划当作成片。页面隐藏时暂停；浏览器受限时记录实际查看的关键帧、375px图和总览范围。

竖屏参考保存在 `assets/scene-reference.svg`，同名PNG用于375px宽查看。该图取自流星篇首版的进入大气镜头，保留可编辑对象、标题和字幕区域。后续沿用色彩、材质与层级，按新选题重新绘制内容。

## 上传封面

用户要求同时交付横版4:3与竖版3:4封面，分别排版；当前制作尺寸为1440×1080及1080×1440。标题、署名、系列名和主要天体保持清晰边距；对象名称紧邻对应图形，缩小查看时仍可辨认。封面只表达本条视频的问题与已审校结论，图中标明科普示意和必要的不按比例说明。文件、文案和版本关联见[上传素材包约定](upload-package-contract.md)。

账号署名使用可编辑的[地理故事工坊字标](../assets/brand-lockup.svg)：书本托起地球，书页延伸为轨道；暖金“地理”、浅色“故事”和“工坊”印记共同组成账号名。与深蓝封面配合，保持原有比例和文字完整性，缩小检查清晰度。将实际使用的字标源文件一并交付到作品的`outputs/`。
